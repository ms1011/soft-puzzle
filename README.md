# 소프트퍼즐 (soft-puzzle)

같은 와이파이(LAN)에 모인 사람들이 터미널만으로 즐기는 카드게임 파티입니다.
설치할 앱도, 계정도, 인터넷도 필요 없습니다 — 한 명이 방을 만들면 나머지는
같은 네트워크에서 자동으로 그 방을 찾아 들어옵니다.

블랙잭·원카드·야추(Yacht)·마피아 네 가지를 지원합니다.

## 요구 사항

- Node.js 22 이상
- 같은 LAN(같은 와이파이/공유기)에 연결된 2~6명

## 설치

npm에 게시된 뒤에는 아래로 설치합니다.

```bash
npm install -g soft-puzzle
```

또는 설치 없이 그때그때 실행만 하려면:

```bash
npx soft-puzzle
```

아직 게시 전이라 저장소에서 직접 써야 한다면, 이 저장소를 clone한 뒤:

```bash
npm install
npm run build
npm install -g ./packages/client
```

## 실행

```bash
soft-puzzle
```

닉네임을 한 번 입력하면 `~/.soft-puzzle.json`에 저장되어 다음부터는 바로 메인
메뉴로 들어갑니다. (저장 위치를 바꾸고 싶다면 `SOFT_PUZZLE_CONFIG` 환경변수로
다른 경로를 지정할 수 있습니다.)

### `--ascii` 옵션

```bash
soft-puzzle --ascii
```

카드·주사위를 그리는 데 쓰는 박스 문자(┌─┐ 등)나 무늬 기호(♠♥♦♣)가 깨지는
구형 터미널(오래된 Windows PowerShell/`cmd.exe`의 conhost 등)에서는 이 옵션으로
순수 ASCII 아트로 강제 전환할 수 있습니다. Windows Terminal이나 ConEmu가 아닌
`win32`에서는 이 옵션 없이도 자동으로 ASCII로 그려집니다. 화면이 깨져 보이면
가장 먼저 이 옵션을 시도해 보세요.

### 방화벽 안내

방을 만들거나(호스트) 방을 찾을 때(참가자) 모두 로컬 네트워크 통신이 필요합니다.
**macOS**와 **Windows** 모두 `soft-puzzle`를 처음 실행할 때 "네트워크의 다른 기기가
이 앱을 찾을 수 있게 허용하시겠습니까?" 같은 방화벽 허용 팝업을 띄웁니다 — **반드시
허용**을 눌러야 방 만들기/방 찾기가 정상 동작합니다. 회사·공용 네트워크처럼
브로드캐스트가 막혀 있는 환경에서는 허용해도 방 목록에 아무것도 안 뜰 수 있는데,
이때는 아래 "수동으로 접속하기"를 쓰세요.

## 방 만들기 (호스트)

1. 메인 메뉴에서 **방 만들기**를 고르고 게임(블랙잭/원카드/야추/마피아)을 선택합니다.
2. 로비 화면 위쪽에 `내 접속 주소: 192.168.x.x:7420`처럼 자신의 접속 주소가
   나타납니다 — 방화벽 때문에 참가자가 방 목록에서 방을 못 찾을 때 이 주소를
   불러주세요.
3. 참가자가 모이면 호스트만 **[Enter]**로 게임을 시작할 수 있습니다.
4. **호스트가 나가면(종료/연결 끊김) 방 전체가 함께 종료됩니다.** 방은 호스트의
   프로세스 안에서만 돌아가기 때문에, 참가자들은 "방장의 연결이 끊겼습니다" 화면을
   보고 메인 메뉴로 돌아갑니다 — 다시 하려면 누군가 새로 방을 만들어야 합니다.

## 방 참가하기

1. 메인 메뉴에서 **방 참가**를 고르면 몇 초간 같은 네트워크의 방을 자동으로
   찾습니다. 방향키로 고르고 **[Enter]**로 입장, **[r]**로 다시 찾기.
2. **수동으로 접속하기**: 방이 안 보이면(방화벽·다른 서브넷 등) **[i]**를 눌러
   호스트가 불러준 주소를 `192.168.0.5:7420` 형식으로 직접 입력합니다.
3. 닉네임이 이미 방 안의 누군가와 같으면(대소문자·자모 조합 차이 무시) 참가가
   거절되고 닉네임을 새로 입력하라는 화면으로 돌아갑니다.

## 게임 중 끊김

누구든 게임 중 나가면(창을 닫거나 Ctrl+C) 서버가 즉시 감지합니다:

- **참가자가 나가면**: 남은 사람들끼리 게임이 계속됩니다. 그 사람 턴이 오면
  자동으로 넘어갑니다.
- **호스트가 나가면**: 방 전체가 끝나고 전원이 "방장의 연결이 끊겼습니다" 화면을
  봅니다.
- **누군가 제한 시간(90초) 안에 아무 행동도 하지 않으면**: 서버가 대신 기본
  행동(패스에 가까운 동작)을 자동으로 골라 진행합니다 — 게임이 멈추지 않습니다.

## 공통 조작

| 키 | 동작 |
| --- | --- |
| 방향키 | 메뉴/목록 이동, 베팅액·카드 커서 이동 |
| Enter | 선택/확인 |
| Esc | 하위 화면·입력 취소 |
| Ctrl+C | 언제든 즉시 종료 (터미널은 정상 상태로 복원됩니다) |

## 게임별 조작

### 블랙잭

| 키 | 동작 |
| --- | --- |
| ↑ / ↓ | 베팅액 ±10 |
| ← / → | 베팅액 ±100 (빠른 조절) |
| Enter | 베팅 확정 / (베팅 후) 준비 |
| h | 히트 |
| s | 스탠드 |
| d | 더블다운 |
| e | 게임 종료(호스트) |

### 원카드

| 키 | 동작 |
| --- | --- |
| ← / → | 낼 카드 선택 |
| Enter | 선택한 카드 내기 (7 낸 뒤에는 좌우로 무늬를 골라 Enter) |
| Esc | 무늬 선택 취소 |
| d | 카드 뽑기 |

### 야추 (Yacht)

| 키 | 동작 |
| --- | --- |
| 1~5 | 그 번째 주사위 홀드/해제 |
| r | 리롤(다시 굴리기) |
| c | 점수 기록할 칸 선택 모드 진입 → ↑/↓로 고르고 Enter로 확정 |
| Esc | 점수 칸 선택 취소 |

### 마피아

4명 이상이 필요합니다. 밤에는 마피아가 처치할 대상을, 낮에는 생존자 모두가 탈락시킬
대상을 고릅니다. **↑ / ↓**로 대상을 선택하고 **Enter**로 투표합니다. 모든 마피아를
찾으면 시민 팀이, 마피아 수가 시민 수와 같아지면 마피아 팀이 승리합니다.

## 결과 화면

한 판이 끝나면 순위표가 뜹니다. 호스트만 **[r] 다시하기** 또는 **[q] 나가기**를
누를 수 있고, 참가자는 호스트의 선택을 기다립니다.

## 문제가 있다면

- 방이 하나도 안 보인다 → 방화벽 허용을 눌렀는지 확인하고, 안 되면 호스트 주소로
  수동 접속([i])하세요.
- 글자가 깨져 보인다(□□□, 물음표 등) → `--ascii`로 다시 실행해 보세요.
- 종료했는데 터미널이 이상해 보인다 → 새 터미널 탭을 열거나 `reset` 명령을
  입력하세요 (정상 종료 시에는 원래 발생하지 않아야 합니다 — 재현되면 이슈로
  남겨주세요).
